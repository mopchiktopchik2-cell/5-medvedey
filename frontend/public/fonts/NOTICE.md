# Шрифты интерфейса

Файлы `*.woff2` в этой папке получены из Google Fonts CSS API и разложены по подмножествам (latin, latin-ext, cyrillic). Используются только локально, без обращения к внешним CDN.

| Шрифт | Начертания | Лицензия | Источник |
| --- | --- | --- | --- |
| Onest | 400–800 | SIL Open Font License 1.1 | https://github.com/googlefonts/onest |
| Manrope | 300–700 | SIL Open Font License 1.1 | https://github.com/sharanda/manrope |
| Playfair Display | italic 500–600 | SIL Open Font License 1.1 | https://github.com/clauseggers/Playfair-Display |
| Roboto Mono | 400–500 | Apache License 2.0 | https://github.com/googlefonts/RobotoMono |

Актуальные тексты лицензий — в указанных репозиториях. При добавлении или замене шрифтов обновите эту таблицу и `frontend/src/fonts.css`.
