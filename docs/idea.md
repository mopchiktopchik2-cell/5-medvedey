# Идея проекта

## Проблема

Швейный цех «М.и.Р.» (Сургут) считает себестоимость мерча вручную: менеджер уточняет у технолога нормо-часы и раскладку, считает метраж и стоимость в таблице, затем вручную оформляет КП. На один расчёт уходит несколько часов, ошибки в формулах и устаревшие цены приводят к пересогласованию с заказчиком.

## Решение

Веб-сервис, который за 5–10 минут считает себестоимость изделия и формирует коммерческое предложение в PDF:

- пошив — по типу изделия, сложности и тиражу;
- раскрой — по деталям кроя, ширине рулона и отходам;
- фурнитура и брендирование — из справочников;
- итог, цена за единицу и срок изготовления;
- история расчётов с поиском и фильтрами;
- публичная ссылка на КП для подрядчика.

Отличие от таблиц в Excel — единые справочники, которые ведёт технолог, проверяемые формулы и готовый документ по кнопке.

## Целевая аудитория

- **Менеджер по подрядчикам** — готовит расчёт и КП для заказчика.
- **Технолог** — ведёт ткани, фурнитуру, нормо-часы, коэффициенты и настройки цеха.
- **Подрядчик** — получает КП по ссылке без регистрации.

## Ключевые сценарии

1. Менеджер выбирает изделие, сложность и тираж, подставляет типовой крой — сразу видит итоговую себестоимость.
2. Меняет ткань, процент отходов или ширину рулона — смета и метраж пересчитываются на лету.
3. Сохраняет расчёт и скачивает PDF-КП; отправляет подрядчику публичную ссылку.
4. Технолог обновляет нормо-часы и справочники — новые расчёты сразу идут с актуальными ценами.
5. Менеджер находит старый расчёт в истории по подрядчику или номеру КП.

## Стек

- Backend: Python 3.11, FastAPI, SQLAlchemy 2.0, SQLite (локально) / PostgreSQL, JWT в httpOnly cookie, fpdf2.
- Frontend: React 19, TypeScript, Vite, React Router.
- Инфраструктура: Docker Compose, GitHub Actions.

## Риски

- **Точность раскладки.** Используется эвристика «полками» с поворотом деталей, а не оптимизатор вложенности. Для экспресс-оценки погрешность приемлема, точный расклад — задача САПР.
- **Данные цеха.** Нормо-часы и коэффициенты нужно сверить с технологом перед боевым запуском; в демо-данных значения ориентировочные.
- **Отправка на email.** SMTP не подключён: в первой версии КП передаётся ссылкой и PDF-файлом.
- **Один экземпляр сервиса.** SQLite подходит для одного цеха; при росте нагрузки — PostgreSQL из `docker-compose.postgres.yml`.
