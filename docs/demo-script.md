# Сценарий показа на 5–6 минут

Демо для заказчика или жюри хакатона. Задача — за отведённое время показать полный путь «заявка → расчёт → КП в PDF → ссылка подрядчику» и не увязнуть в деталях.

## Подготовка за 5 минут до выхода

```powershell
cd 5-medvedey
.\scripts\dev.ps1
```

1. Открыть http://localhost:5173 и войти технологом: `technologist@mir.ru` / `technolog123`.
2. Пройти сценарий один раз целиком — Vite скомпилирует страницы, и на показе не будет пауз.
3. Открыть вторую вкладку с http://localhost:5173 — в ней будем показывать публичную ссылку.
4. Проверить, что скачивается PDF (кнопка «Скачать PDF»).
5. Закрыть лишние окна и уведомления, включить режим «Не беспокоить».

Всё работает без интернета: шрифты, PDF и данные — локально. Если Docker-вариант (`.\scripts\start-lan.ps1`), адрес будет `http://<IP>:8080`, входы те же.

## Тайминг и текст

### 0:00–0:30 — проблема

> «КП в цехе считается в Excel: менеджер собирает цены, технолог отдельно считает нормо-часы, потом всё это вручную переносится в Word. Два-три часа на один расчёт и почти гарантированная ошибка при каждой правке тиража».

### 0:30–1:15 — расчёт пошива

Действия:

1. Вход менеджером: `manager@mir.ru` / `manager123`.
2. На экране «Калькулятор»: изделие **Футболка**, тираж **100 шт.**, сложность **Базовая**, ткань **Кулирка хлопок 160 г/м²**.
3. Отметить **карманы** — смета справа пересчитывается сама.

> «Справочники уже заполнены: десять тканей, фурнитура, изделия, коэффициенты сложности. Менеджер выбирает из списка, а не вводит цены руками».

### 1:15–2:15 — раскрой

1. Прокрутить до блока деталей кроя: перед, спинка, рукав (подставляются автоматически для футболки).
2. Показать ширину рулона **180 см**, отходы **18 %**, припуск **1,5 см**.
3. Обратить внимание на метраж и стоимость материала в смете.

> «Раскладка считается по ширине рулона: детали поворачиваются, считается метраж с отходами. Это то место, где Excel обычно врёт».

### 2:15–3:30 — КП, PDF и ссылка подрядчику

1. Нажать **«Сохранить расчёт»** — открывается карточка предложения с номером.
2. Нажать **«Скачать PDF»** — открывается готовый документ с логотипом, реквизитами и таблицей.
3. Нажать **«Ссылка для подрядчика»** — ссылка копируется, рядом видно срок действия.
4. Переключиться на вторую вкладку, вставить ссылку: подрядчик видит состав, цены и итог, но **не видит** нормо-часы, цену метра ткани, email и ФИО сотрудников.
5. Вернуться и нажать **«Отозвать ссылку»**, обновить вторую вкладку — страница отдаёт 404.

> «Ссылка живёт 30 дней и отзывается в один клик. Это закрытый URL: без входа, но и без внутренней кухни».

### 3:30–4:15 — история

1. Перейти в **«История»**, найти расчёт по номеру.
2. Показать фильтр по дате и экспорт CSV.

> «Вся история и отчётность выгружаются в CSV — бухгалтерии и руководителю ничего переписывать не нужно».

### 4:15–5:15 — технолог

1. Выйти, войти технологом.
2. **«Справочники»** → ткани: показать, что цены и ширины редактируются.
3. Изменить нормо-час швеи на 10 % выше, вернуться в калькулятор — сумма в смете выросла.
4. Вкладка **«Пользователи»**: создать сотрудника, показать отключение уволенного.

> «Менеджер видит только свои расчёты и не может менять цены. Технолог управляет справочниками и сотрудниками».

### 5:15–6:00 — итог

> «Итого: расчёт и готовый PDF — 3–5 минут вместо двух часов. Данные остаются на сервере цеха, без внешних облаков. 62 теста бэкенда, 13 фронтенда, миграции и CI — всё в репозитории».

## Если что-то пошло не так

| Ситуация | Что делать |
| --- | --- |
| Сайт не открывается | Перезапустить `.\scripts\dev.ps1`, подождать 10–15 секунд |
| Пропал интернет | Ничего: всё локальное, демо работает офлайн |
| Не работает PDF | Показать карточку КП на экране; PDF формируется на сервере и проверен тестами |
| Демо-база «загрязнилась» | Не чистить на ходу: показать историю как есть, она выглядит реалистично |
| Вход не принимается | Проверить раскладку и Caps Lock; демо-пароли: `manager123`, `technolog123` |

## Заготовки ответов на вопросы

- **«Это точно считается?»** Формулы открыты в README и покрыты тестами: раскрой, пошив, фурнитура, брендирование, сроки. Деньги — в `Decimal`, округление только на выводе.
- **«А если ткань другая?»** Технолог добавляет её в справочник, менеджер сразу выбирает. Цена и ширина рулона участвуют в раскладке.
- **«Где данные?»** SQLite или PostgreSQL на вашем сервере, файл `backend/data/app.db`, логотип в `data/uploads`, PDF не хранится и собирается при скачивании.
- **«Можно поставить у нас в цехе?»** Да: `.\scripts\start-lan.ps1`, доступ по `http://<IP>:8080`; для интернета — Docker + домен + TLS по README.
- **«Сколько стоит эксплуатация?»** Один VPS в РФ; внешних платных API нет.
